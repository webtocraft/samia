# 🌾 সামিয়া এন্টারপ্রাইজ (Samiya Enterprise)
> **স্মার্ট কৃষি ব্যবসা ও ধান ব্যবস্থাপনা সিস্টেম**

সামিয়া এন্টারপ্রাইজ একটি আধুনিক মিনি বিজনেস ইআরপি (Mini Business ERP) সিস্টেম, যা ধান কেনাবেচা, হাওলাদ (বকেয়া), পরিশোধ এবং বস্তাপ্রতি কেজির হিসাব নিখুঁতভাবে ডিজিটাল উপায়ে পরিচালনা করার জন্য তৈরি করা হয়েছে।

---

## ✨ মূল বৈশিষ্ট্যসমূহ (Key Features)
- **হাওলাদ ও বকেয়া ট্র্যাকিং:** তারিখ অনুযায়ী বাকিতে ধান কেনা বা বিক্রির হিসাব।
- **বস্তা ও কেজির হিসাব:** ধানের মোট বস্তা এবং প্রতি বস্তায় কেজির সঠিক হিসাব।
- **লেনদেন ব্যবস্থাপনা:** ক্যাশ ও ওয়ালেট ভিত্তিক জমা-খরচ এবং পরিশোধের হিসাব।
- **আধুনিক ইন্টারফেস:** মোবাইল এবং ডেস্কটপ উভয় ডিভাইসে দারুণভাবে রেসপন্সিভ।

---

## 🛠️ প্রযুক্তি ও টেক স্ট্যাক (Tech Stack)
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend / Logic:** Google Apps Script (GAS)
- **Database:** Google Sheets
- **Design & Styling:** WebToCraft Custom UI
